NekoRay NT5 - components and licenses
=====================================

This is a technical list, not legal advice.

About NekoRay NT5
  NekoRay NT5 is an independent, community-maintained fork and adaptation of NekoRay for Windows XP
  SP3 and Windows 2000 SP4 (x86). It is not an official NekoRay release and is not endorsed by the
  NekoRay maintainers. Its NT5-specific implementation and compatibility work are specific to this
  project and are not part of any upstream NekoRay release.
  Original project: NekoRay, https://github.com/MatsuriDayo/nekoray, license GPL-3.0.

xray.exe - Xray-core 1.8.3 (Project X), windows/386

  with two small changes for Windows XP (nt5-ui/third_party: a go.mod replace and a one-line change
  of github.com/sagernet/wireguard-go), built with the Go toolchain described below.

  license texts and NOTICE files are in the folder xray-modules (INDEX.txt lists them).

  xray.exe as a whole is distributed under GPL-3.0 terms; its complete corresponding source is
  described in nt5-ui/third_party/README.md of the source repository.
