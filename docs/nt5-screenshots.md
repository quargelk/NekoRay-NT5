# NekoRay NT5 — снимки экрана

Все снимки в `docs/screenshots/` — снимки **настоящей программы** NekoRay NT5 0.9.7-dev1 с
синтетическими данными: документационные адреса (RFC 5737, `example.com`), UUID из нулей,
ключи-заглушки. Настоящих серверов, подписок, ключей, паролей и имён пользователей на снимках нет;
системный прокси при съёмке не включался.

## 1. Галерея возможностей — хост Windows 11 (шесть снимков)

Сделаны на сборочном компьютере с **Windows 11**, не на Windows XP и не на Windows 2000; в README
так и подписаны.

| Файл | Что на снимке | Как получен |
|---|---|---|
| `main-window.png` | Главное окно, примеры серверов (английский интерфейс) | `nt5-ui/tests/make-screenshots.cmd` |
| `main-window-ru.png` | То же, русский интерфейс | `make-screenshots.cmd ... ru` |
| `add-servers.png` | Окно Add с предпросмотром | `make-screenshots.cmd` |
| `settings-subscriptions.png` | Settings -> Subscriptions (HWID показан сокращённо) | `make-screenshots.cmd` |
| `diagnostics.png` | Diagnostics на Windows 11 | `make-screenshots.cmd` |
| `connected-local-test.png` | Состояние «подключено»: настоящий Xray 1.8.3 и локальный тестовый сервер VLESS + REALITY + Vision на 127.0.0.1 с ключами, созданными для этого снимка | отдельный одноразовый скрипт вне репозитория |

`make-screenshots.cmd` загружает окна из собранного `NekoRayNT5.exe`, заполняет их синтетическими
данными и сохраняет изображения окон (подробности — `nt5-ui/tests/Screenshots.cs`).

## 2. Снимки с настоящих целевых систем (два снимка, готовы)

Сделаны сопровождающим на настоящих системах с пакетом 0.9.7-dev1, клавишами Alt+PrintScreen
(только окно программы). Содержимое снимков не редактировалось.

| Файл | Система | Что на снимке |
|---|---|---|
| `windows-xp-main.png` | Windows XP SP3 (Windows NT 5.1, сборка 2600) | Главное окно в режиме ожидания, русский интерфейс, пять синтетических примеров серверов; «Не запущено», системный прокси выключен |
| `windows-2000-diagnostics.png` | Windows 2000 SP4 (Windows NT 5.0, сборка 2195) | Diagnostics: строка Windows со статусом «Note» и текстом о проверенной конфигурации (без KernelX); Core и Helper — «present, loadable»; сертификаты (121), curl.exe не нужен, локальные порты свободны |

Оба снимка проверены перед публикацией: в них нет личных путей, настоящих адресов, UUID, ссылок
подписок, учётных данных и текстовых метаданных PNG.

## 3. Правила для новых снимков

1. Отдельная папка данных, чтобы не затронуть и не показать свои профили. В «Командной строке»:

   ```
   set NEKORAY_NT5_DATA_DIR=C:\nt5-shots
   cd /d C:\Programs\NekoRayNT5
   NekoRayNT5.exe
   ```

   Программу запускать из этого же окна `cmd`; при первом запуске появится помощник первого запуска.
2. Только синтетические ссылки (подключиться к ним нельзя, и это не нужно):

   ```
   vless://00000000-0000-4000-8000-000000000000@203.0.113.10:443?security=reality&pbk=AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA&sni=www.example.com&fp=chrome&sid=01&flow=xtls-rprx-vision#Example VLESS Reality
   vless://00000000-0000-4000-8000-000000000000@203.0.113.11:443?security=tls&type=ws&host=cdn.example.com&path=%2Fws&sni=cdn.example.com#Example VLESS WebSocket
   trojan://example-password@198.51.100.20:443?security=tls&sni=trojan.example.net#Example Trojan
   ss://Y2hhY2hhMjAtaWV0Zi1wb2x5MTMwNTpleGFtcGxlLXBhc3N3b3Jk@198.51.100.30:8388#Example Shadowsocks
   socks://198.51.100.40:1080#Example SOCKS5
   ```

3. Снимать только окно программы: щёлкнуть по нему и нажать **Alt+PrintScreen**, вставить в Paint
   и сохранить как PNG. Paint в Windows 2000 обычно не сохраняет PNG: сохранить как 24-разрядный
   BMP и преобразовать в PNG на другом компьютере без других изменений.
4. Перед публикацией открыть снимок и проверить, что в нём нет имени пользователя, путей с именем
   пользователя, настоящих адресов и других личных данных. Содержимое не редактировать (допустима
   только обрезка по краям окна).
5. Снимки с хоста подписывать как снимки Windows 11; снимки с целевых систем — с точным названием
   системы.
