# NekoRay NT5 — снимки экрана

## 1. Что уже есть (используется в README)

В `docs/screenshots/` лежат шесть снимков **настоящей программы** NekoRay NT5 0.9.7-dev1. Все они
сделаны на **сборочном компьютере с Windows 11** (в README так и подписаны), не на Windows XP и не
на Windows 2000. Данные только синтетические: документационные адреса (RFC 5737, `example.com`),
UUID из нулей, ключи-заглушки; настоящих серверов, подписок, ключей и имён пользователей на снимках
нет. Системный прокси при съёмке не включался.

| Файл | Что на снимке | Как получен |
|---|---|---|
| `main-window.png` | Главное окно, примеры серверов (английский интерфейс) | `nt5-ui/tests/make-screenshots.cmd` |
| `main-window-ru.png` | То же, русский интерфейс | `make-screenshots.cmd ... ru` |
| `add-servers.png` | Окно Add с предпросмотром | `make-screenshots.cmd` |
| `settings-subscriptions.png` | Settings -> Subscriptions (HWID показан сокращённо) | `make-screenshots.cmd` |
| `diagnostics.png` | Diagnostics на Windows 11 | `make-screenshots.cmd` |
| `connected-local-test.png` | Состояние «подключено»: настоящий Xray 1.8.3 и локальный тестовый сервер VLESS + REALITY + Vision на 127.0.0.1 с ключами, созданными для этого снимка | отдельный одноразовый скрипт вне репозитория |

`make-screenshots.cmd` загружает окна из собранного `NekoRayNT5.exe`, заполняет их синтетическими
данными и сохраняет изображения окон (подробности — в `nt5-ui/tests/Screenshots.cs`). Эти снимки
остаются основной галереей README.

## 2. Что осталось снять вручную (два снимка)

Нужны только два снимка с настоящих целевых систем. Подключение к серверу для них **не нужно**:
не нужны ни настоящий сервер, ни настоящий UUID, ни адрес подписки, ни пароли.

| № | Файл | Система | Что на снимке |
|---|---|---|---|
| 1 | `windows-xp-main.png` | Windows XP SP3 | Главное окно с синтетическими примерами серверов |
| 2 | `windows-2000-diagnostics.png` | Windows 2000 SP4 | Окно Diagnostics со строками Core и Helper |

Когда оба файла готовы, их кладут в `docs/screenshots/` с этими именами и добавляют в раздел
README «Screenshots from Windows XP and Windows 2000» (и в `README.ru.md`, раздел «Снимки экрана с
Windows XP и Windows 2000»), подписав систему, на которой они сняты.

### Общие меры безопасности данных (для обоих снимков)

1. Работайте с **отдельной папкой данных**, чтобы не затронуть и не показать свои настоящие
   профили. Откройте «Командную строку» (Пуск -> Выполнить -> `cmd` -> OK) и введите, заменив путь
   на папку, где лежит программа:

   ```
   set NEKORAY_NT5_DATA_DIR=C:\nt5-shots
   cd /d C:\Programs\NekoRayNT5
   NekoRayNT5.exe
   ```

   Программа запустится с пустой папкой данных `C:\nt5-shots`; ваши данные в `%APPDATA%\NekoRayNT5`
   не используются. Запускайте программу **из этого же окна** `cmd`.
2. При первом запуске появится помощник первого запуска: закройте его или пройдите до конца, ничего
   не добавляя.
3. Используйте только эти синтетические ссылки (документационные адреса; подключиться к ним нельзя,
   и это не нужно):

   ```
   vless://00000000-0000-4000-8000-000000000000@203.0.113.10:443?security=reality&pbk=AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA&sni=www.example.com&fp=chrome&sid=01&flow=xtls-rprx-vision#Example VLESS Reality
   vless://00000000-0000-4000-8000-000000000000@203.0.113.11:443?security=tls&type=ws&host=cdn.example.com&path=%2Fws&sni=cdn.example.com#Example VLESS WebSocket
   trojan://example-password@198.51.100.20:443?security=tls&sni=trojan.example.net#Example Trojan
   ss://Y2hhY2hhMjAtaWV0Zi1wb2x5MTMwNTpleGFtcGxlLXBhc3N3b3Jk@198.51.100.30:8388#Example Shadowsocks
   socks://198.51.100.40:1080#Example SOCKS5
   ```

4. **Не нажимайте Connect** и не включайте System Proxy.
5. Снимайте **только окно программы**: щёлкните по нему и нажмите **Alt+PrintScreen** (снимок
   активного окна, без рабочего стола и других окон).
6. Перед отправкой откройте снимок и проверьте, что на нём нет имени пользователя, путей с именем
   пользователя, настоящих адресов и других личных данных.
7. Не редактируйте содержимое снимка (кроме обрезки по краям окна) — снимок должен быть настоящим.

### Снимок 1: `windows-xp-main.png` — главное окно в Windows XP SP3

1. Система: **Windows XP SP3 x86** с .NET Framework 2.0. Тема — стандартная (Luna) или
   классическая; разрешение экрана 800×600 или больше.
2. Распакуйте пакет `NekoRayNT5-v0.9.7-dev1-win32.zip` и запустите программу с отдельной папкой
   данных (пункт 1 общих мер).
3. Интерфейс должен быть английским (так по умолчанию; если нет — Settings -> General -> Language ->
   English и перезапуск из того же окна `cmd`).
4. Нажмите **Add...**, вставьте пять синтетических ссылок (пункт 3 общих мер), нажмите **Check**,
   затем **Add**.
5. Щёлкните один раз по строке **Example VLESS Reality**, чтобы она была выделена. Не подключайтесь.
   В строке состояния внизу должно быть «Not Running».
6. Если окно маленькое, растяните его примерно до 800×600, чтобы были видны список серверов и
   журнал.
7. Щёлкните по заголовку окна и нажмите **Alt+PrintScreen**.
8. Откройте Paint (Пуск -> Программы -> Стандартные -> Paint), нажмите **Ctrl+V**, затем
   Файл -> Сохранить как -> тип файла **PNG** -> имя `windows-xp-main.png`.
9. Перенесите файл в репозиторий: `docs/screenshots/windows-xp-main.png`.

### Снимок 2: `windows-2000-diagnostics.png` — Diagnostics в Windows 2000 SP4

1. Система: **Windows 2000 SP4 x86** с .NET Framework 2.0 (как в проверенной конфигурации:
   без KernelX, с установленными корневыми сертификатами).
2. Распакуйте пакет и запустите программу с отдельной папкой данных (пункт 1 общих мер).
   Серверы добавлять не нужно.
3. На панели инструментов нажмите **Diagnostics...**.
4. В списке должны быть видны строки **Windows**, **Core (xray.exe)**, **Helper (nt5helper.exe)**,
   **Certificates (cacert.pem)** и другие. Щёлкните по строке **Windows**, чтобы внизу был виден
   текст о Windows 2000 (статус этой строки — «Note»; это ожидаемо).
5. Проверьте, что в строках Core и Helper указано, загружаются ли они (например, «present,
   loadable»). Если там ошибка, сохраните снимок всё равно и сообщите о ней отдельно — снимок не
   подправляют.
6. Щёлкните по заголовку окна Diagnostics и нажмите **Alt+PrintScreen**.
7. Откройте Paint, нажмите **Ctrl+V** и сохраните файл. Paint в Windows 2000 обычно не умеет
   сохранять PNG: сохраните как **24-разрядный BMP** (`windows-2000-diagnostics.bmp`) и уже на
   другом компьютере преобразуйте в PNG без других изменений (например, откройте в Paint на
   Windows XP или новее и сохраните как PNG).
8. Перенесите файл в репозиторий: `docs/screenshots/windows-2000-diagnostics.png`.

Снимок «подключено» с Windows XP или Windows 2000 не требуется.
