# NekoRay NT5 v0.9.7-dev1

First public **development release** of NekoRay NT5, an independent adaptation of
[NekoRay](https://github.com/MatsuriDayo/nekoray) for Windows XP SP3 and Windows 2000 SP4 (x86).
It is not a stable release and not an official NekoRay release.

## Highlights

- **One package for Windows XP SP3 and Windows 2000 SP4.** `xray.exe` (Xray-core 1.8.3) and
  `nt5helper.exe` are built with a Go 1.20 toolchain that has the Windows XP backport plus this
  project's Windows 2000 (NT 5.0) patch: PE version 5.0, exception handling without vectored
  handlers, `CryptGenRandom`, TCP connect without `ConnectEx`, name lookup without `GetAddrInfoW`.
  Each fallback is chosen at run time, so Windows XP keeps its normal code paths.
- **Windows 2000 without KernelX.** The tested Windows 2000 SP4 configuration needs no extended
  kernel (see "Tested" below).
- Profiles and subscriptions: VLESS (REALITY, Vision), VMess, Trojan, Shadowsocks, SOCKS5; one Add
  command for links, lists, files, `http(s)://` subscriptions and `happ://add/` links, with a preview.
- HTTPS subscriptions with TLS 1.2/1.3 through `nt5helper.exe` and the bundled Mozilla CA list.
- System Proxy (WinINet) with restore on Disconnect, Exit, errors, log-off and after a crash.
- English and Russian interface; Diagnostics with a report free of addresses, keys and user names.
- The Windows 2000 Diagnostics text now describes the tested configuration instead of naming
  KernelX as required.

configurations have not been tested and may behave differently.

## Requirements

Windows XP SP3 x86 or Windows 2000 SP4 x86, .NET Framework 2.0, a processor with SSE2 (Pentium 4,
Athlon 64 or newer). Up-to-date root certificates are recommended (they were installed in the
tested Windows 2000 configuration).

## Known limitations

- Development release; no automatic updates, no installer.
- No TUN / system-wide mode; System Proxy covers only programs that use the Windows proxy settings.
- No Hysteria, TUIC or Naive; no Clash / sing-box / Xray-JSON subscriptions; no encrypted
  `happ://crypt...` links; no traffic statistics; subscriptions are updated by hand.
